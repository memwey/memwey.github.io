王司徒的道理
Posted on 2024-12-25:: History

整理自我在知乎问题 诸葛亮王朗论战, 我感觉王朗说得好有道理怎么办? 下的回答.

如果抛开演义的修饰结合正史, 王司徒的话确实不无道理.

倘若真如诸葛亮所说 "吾素知汝所行", 那王司徒的前半生可以好好探讨一下.

王朗前半生主要在地方任职. 他曾任会稽太守, 在任时获百姓爱戴. 随后孙策入侵江东, 王朗抵抗不敌, 转移到侯官 (今福建福州), 与侯官县长商升联合继续对抗孙策. 而后商升慑于孙策威名打算投降, 引发内乱, 终被孙策平定. 王朗意图前往交州继续抵抗, 出海时被孙策追击, 被迫投降. 孙策敬重其为人, 不加害并予以招揽, 王朗不从. 建安三年, 曹操上表征召王朗, 因久经战乱道路不通, 王朗辗转数年才到任, 由此开启了他作为中央官员的后半生.

从孙策的角度来看, 平定江东的故事仿佛顺水推舟. 但是对于汉朝中央政府来说, 江东并不是无主之地. 王朗是中央政府正式任命的地方长官, 有势力以武力强夺地方政权, 他与之对抗理所应当. 王朗长于治理而弱于军事, 被孙策打败并不奇怪. 但是从他治理地方清平, 抵御外敌坚决的经历来看, 他完全对得起这份汉禄.

汉室倾颓有两条脉络, 一是中央混乱, 二是地方割据. 从地方长官王朗的角度来看, 刘备, 孙策这些袭击中央任命的地方长官, 造成地方实际割据的人, 是不是也需要为汉室倾颓负一部分责任? 刘璋, 刘繇, 刘表这些中央任命驻守地方的汉室宗亲, 难道都是应该被讨伐的乱臣贼子?

孙策奉袁术之命讨伐江东, 实为割据, 而袁术随后公开称帝. 益州刘璋, 荆州刘琮暗弱, 意图向中央归降, 刘备夺其州郡, 兼并其众. 个人能力有限, 王朗只能做治世之能臣, 做不了乱世之奸雄. 但是汉室倾颓的责任, 相比起王朗, 刘备, 孙策这些人可大得多.

只是这层两方都是汉室倾颓元凶的道理, 怎么能在两军阵前明说? 这种潮流滚滚向前, 力不从心的心情, 又怎么能在两军阵前细说?
